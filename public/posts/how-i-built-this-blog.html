我是如何用一小时搭好这个博客的

2026年10月3日
教程建站

很多人觉得"建一个自己的网站"是件很技术的事。其实只要找对工具，一小时内就能搞定，而且完全免费。

为什么不用现成的博客平台

现成的平台当然方便，但有两个问题：一是你的内容存在别人的服务器上，二是页面风格很难改。而用静态网站的方式，所有文章都在你自己的仓库里，随时可以搬走。

整体思路

这个博客的实现思路非常简单：

  1. 文章用 Markdown 文件保存，放在 content/posts/ 目录
  2. 一个生成脚本把这些文件转换成网页
  3. 网页托管在 Gitee Pages 上，免费且国内访问快

日常维护有多简单

写完文章之后，只需要两步：

npm run build
git add . && git commit -m "新文章" && git push

第一行生成网页，第二行把改动推送到 Gitee。等一两分钟，网站就更新了。

如果你连命令行都不想碰，直接用后台编辑器，点一下保存按钮就行。

写在最后

工具是为了让人更专注于内容本身。希望这个网站能让我多写一点，少纠结一点。
