# 个人博客

一个简洁的个人博客，支持在线写作后台。

## 快速开始

```bash
npm install        # 首次使用，安装依赖
npm run build      # 生成网站
npm run preview    # 本地预览
```

## 写文章

- **在线后台**：打开 `/admin/`
- **直接编辑**：在 `content/posts/` 新建 `.md` 文件
- **命令行**：`npm run new`

## 改网站信息

编辑 `content/site.json`，或用后台的「网站信息」区域。

## 发布平台说明

网站托管使用**腾讯云 EdgeOne Pages**（Gitee Pages 免费版已下线）。
Gitee 仓库用于存放代码和支撑写作后台。

## 目录结构

```
content/     你写的内容（文章 + 网站信息）
public/      生成的网站（自动生成，勿手改）
admin/       在线写作后台
src/         程序代码
```
